## Reproduction

1. Place the source CSV files alongside the notebook or Python script.
2. Install dependencies listed in `requirements.txt` (for example, `pip install -r requirements.txt`).
3. Open the notebook and execute its cells in order, or run the Python script.
4. Review the executed reference outputs and compare the four ANN experimental variants using the common 674-record test partition.

The model-training process is stochastic and performance metrics may vary across runtime environments or dependency versions. The included notebook preserves previously executed reference results.

## Methodological notes

The study employs a stratified, group-aware **70/20/10 split**, training-only scaling and training-only K-Means cluster assignment. The original source includes **7,043 records**, but only copies of **training profiles** are retained in the original-data training experiment. Copies linked to validation or test profiles are excluded from training to prevent overlapping held-out cases. Both dataset versions are evaluated against the same 674 test records.

`SeniorCitizen` is retained as a 0/1 binary feature. The Data Engineer's upstream standardisation is recognised as an exploratory preparation decision; the ANN-specific representation is selected for interpretability and consistent binary encoding.

The Stage 2 `Cluster` column is retained in the supplied file as a descriptive reference. For independent predictive validation, ANN Model B uses cluster labels generated by K-Means trained on the training partition only.
